## Tailsass documentation

Tailsass is a utility-first CSS/Sass toolkit. These docs explain the available classes and how to use them in your HTML or component templates.

- **[Getting started](./getting-started.md)**: install, configure, and import the library.

### Utility reference

- **[Preflight](./utilities/preflight.md)**: base styles and resets.
- **[Spacing](./utilities/spacing.md)**: margin, padding, gap, and positional spacing.
- **[Sizing](./utilities/sizing.md)**: width/height helpers.
- **[Typography](./utilities/typography.md)**: text alignment, truncation, and font styles.
- **[Fonts](./utilities/fonts.md)**: load a custom typeface and apply it globally or with your own classes.
- **[Colors](./utilities/colors.md)**: background, text, border, outline, shadow, and accent colors.
- **[Borders](./utilities/borders.md)**: border style, width, and radius.
- **[Display & layout](./utilities/display.md)**: display modes, flexbox, grid, floats, visibility, alignment, z-index, and screen-reader helpers.
- **[Position](./utilities/position.md)**: position values combined with spacing offsets.
- **[Lists](./utilities/lists.md)**: list marker styles.
- **[Overflow](./utilities/overflow.md)**: scroll, clip, and hide overflowing content.
- **[Cursor](./utilities/cursor.md)**: cursor styles for interactive elements.
- **[Effects](./utilities/effects.md)**: opacity helpers.
- **[Animation](./utilities/animation.md)**: animations and transitions.
- **[Transform](./utilities/transform.md)**: translate helpers for sliding and motion.

You can copy any of the examples into your `.md` files as fenced code blocks to document usage in your own projects.
