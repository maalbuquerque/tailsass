# Contributing

Forks and pull requests are welcome.

This project is maintained **best-effort** (no response-time promises). PRs are more likely to be merged when they:

- Fit the existing utility style and naming
- Stay small and focused
- Include a short note on why the change helps

Large redesigns or “add every possible class” requests may be declined — please fork if you need a broader fork of the API.

Issues are fine for clear bugs; feature ideas may sit unanswered.
